# U of T Engineering — Applicant Evaluation Rubrics

**Assessment Type:** `written_communications`, `oral_communications`, `logical_thinking`

This document contains the official scoring rubrics for all three BBA applicant assessments. All scores use 0.1 increments (1.0, 1.1, 1.2... 5.0).

---

## Question 1: Written Communication Skills

**Assessment Type:** `written_communications`

*How well did the applicant demonstrate clarity, organization/coherence, meaning/development, and proposed engagement with U of T Engineering?*

| Criterion | 1 - Poor | 2 - Fair | 3 - Good | 4 - Great | 5 - Excellent |
|---|---|---|---|---|---|
| **Clarity** | | | | | |
| *How understandable and clear is the response?* | | | | | |
| Difficult to understand. | Somewhat difficult to understand. | Overall understanding of the response is not significantly affected. | Clear and easy to understand despite minor lapses. | Clear and easy to understand without any lapses. |
| **Organization/Coherence** | | | | | |
| *Unity, logical progression, and connection of ideas* | | | | | |
| Disorganized. No aspects of unity, progression, or coherence of ideas. No connection between ideas. | Somewhat disorganized. Some aspects of unity, progression, and coherence of ideas. May be obscured connections between ideas. | Well organized. Demonstrates all aspects of unity, progression, and coherence of ideas. May contain occasional redundancy. Somewhat connections between ideas or digressions from ideas. | Very well organized. Demonstrates all aspects of unity, progression, and coherence of ideas. Clear connection between ideas. | Extremely well organized. Demonstrates clearly all aspects of unity, progression, and coherence of ideas. Very clear connections between ideas. |
| **Meaning/Development** | | | | | |
| *Relevance and depth of explanations and ideas* | | | | | |
| Little meaning and development. Insufficient or irrelevant explanations and/or details. | Some meaning and development. Somewhat relevant explanations and details. Relationships between ideas unclear. | Good meaning and development. Relevant explanations and details though some points may not be fully elaborated. | Very good meaning and development. Very relevant explanations and/or details. | Excellent meaning and development. Thorough and very relevant explanations and/or details. |
| **Proposed Engagement** | | | | | |
| *Quality of proposed engagement with the university community* | | | | | |
| Vague or generalized proposal. Poor connection between reflection and U of T, no detail in describing the proposed engagement. | Somewhat vague or generalized proposal. Fair connection between reflection and U of T, some detail in describing the proposed engagement. | Evident proposal. Good connection between reflection and U of T, moderate detail in describing the proposed engagement. | Clear proposal. Strong connection between reflection and U of T, with good detail in describing the proposed engagement. | Extremely clear proposal. Excellent connection between reflection and U of T, with very good detail in describing the proposed engagement. |

## Question 3: Logical Thinking Skills

**Assessment Type:** `logical_thinking`

*Looking for: Relevance of three variables (quality of thinking), rationale for three variables (integration of variables into solution), the quality of the answer, and their comfort with ambiguity.*

| Criterion | 1 - Poor | 2 - Fair | 3 - Good | 4 - Great | 5 - Excellent |
|---|---|---|---|---|---|
| **Relevance of Variables** | | | | | |
| *Quality and appropriateness of variables or factors identified* | | | | | |
| The variables identified are not relevant to the problem. Variables addressing the main line of logical thinking is absent. | One or two variables identified are relevant to the problem (including variables addressing the main line of logical thinking). | Two or three variables identified are relevant to the problem (including variables addressing the main line of logical thinking). | The three variables identified are relevant to the problem (including variables addressing the main line of logical thinking). | The three variables identified are very relevant to the problem (including variables addressing the main line of logical thinking). |
| **Rationale for Variables** | | | | | |
| *Integration and explanation of why variables were chosen* | | | | | |
| The rationale for the answer is not clearly explained. Lack of elaboration or use of examples. | The rationale for the answer is weakly explained. Some elaboration and/or use of examples. | The rationale for the answer is reasonably explained. Good elaboration and/or use of examples. | The rationale for the answer is well explained. Great elaboration and/or use of examples. | The rationale for the answer is very well explained. Excellent elaboration and/or use of examples. |
| **Quality of Answer** | | | | | |
| *Directness and completeness of the overall response* | | | | | |
| The applicant does not answer the question, or the answer is very poor. | The applicant does not directly answer the question. | The applicant answers the question. | The applicant answers the question well. | The applicant answers the question very well. |
| **Comfort with Ambiguity** | | | | | |
| *Ability to handle uncertain, unclear, or open-ended problems* | | | | | |
| The applicant portrays a lot of discomfort with the ambiguities within the problem. | The applicant portrays some discomfort with the ambiguities within the problem. | Comfort with the ambiguities within the problem is difficult to assess (or neutral). | The applicant is reasonably comfortable with the ambiguities within the problem. | The applicant is very comfortable with the ambiguities within the problem. |
